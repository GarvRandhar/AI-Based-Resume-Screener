# Resume Screener — React UI

Vite + React + TypeScript frontend for the Resume Screener POC.

## Dev

```bash
# API must be running on :8000
npm install
npm run dev
# → http://localhost:5173
```

## Build

```bash
npm run build
npm run preview
```

## Config

| Variable | Default | Meaning |
|----------|---------|---------|
| `VITE_API_BASE` | `http://127.0.0.1:8000` | FastAPI base URL |

Create `frontend/.env.local` to override.
